# User Guide

- Public catalog: Use the Home page to search and filter items.
- Item details: Shows description and allows placing a hold via email.
- Kiosk: /Kiosk — touch-friendly lookup and checkout.
- Reception: Borrow/Return and Borrower management (Reception role required).
- Branch management: /Branches — view branches and transfer items (Manager/Admin/Reception roles).
- Import: /Import — paste CSV to import items (Admin/Manager roles).
- Notifications: /Notifications — staff-facing log of simulated messages (Manager/Admin/Reception roles).
- Manager exports: /Manager/ExportCsv to download a CSV report of items.

Security: Role-based access restricts admin/reception/manager areas. API access requires X-Api-Key header.
