# Requirements (Assignment 3)

This document summarises the Assignment 3 requirements implemented in this project:

- Public self-service kiosk (touch-friendly, lookup by code/email, checkout)
- Read-only public API endpoints (available items, categories, operating status)
- Notification simulator and log for borrow/reservation/fine events
- Multi-branch inventory with branch transfers and branch-aware items
- Digital reservation / waitlist with FIFO queue and notifications
- CSV importer for bulk catalog ingestion
- Manager analytics and CSV export functionality

Each requirement is implemented to reuse existing repository logic and minimize changes to the original Assignment 2 codebase where possible.
