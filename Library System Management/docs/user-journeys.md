# User Journeys

1. Patron (Kiosk)
- Arrives at kiosk, enters their email/username, views outstanding items and due dates, checks out available items via the kiosk checkout form.

2. Patron (Public site)
- Searches the catalog, visits an item detail page and places a hold by entering their email; when item is returned the system notifies the patron.

3. Reception staff
- Login with Reception role, use Borrow page to borrow items for patrons, return items, and manage borrowers. When returning an item with a reservation queue the next patron is notified automatically.

4. Manager
- Views dashboard for counts and fine summaries, exports CSV reports, views notification log to audit messages.

5. Admin
- Manages inventory, imports items via CSV uploader, views branches and can transfer items between branches.
